# Changelog

All notable changes to the **Auranova** theme will be documented in this file.

## [1.0.0] - 2026-10-31

### Initial Release
- **Pure Online Store 2.0 Architecture:** JSON templates throughout with full section support.
- **Design Tokens System:** 5 customizable color schemes, fluid clamp typography, radii, and spacing variables.
- **Micro JS Runtime:** Zero jQuery or heavy libraries; dependency-free native Web Components (`<cart-drawer>`, `<predictive-search>`, `<product-form>`, `<quantity-input>`, `<back-to-top>`).
- **Cart API & Section Rendering:** Real-time Ajax cart drawer with dynamic free shipping progress bar and cart notes.
- **Accessibility:** Semantic HTML5, skip to content link, WCAG 2.1 AA focus visible outlines, keyboard focus trap on all overlays.
- **SEO & Performance:** Full JSON-LD structured data (Product, Organization, WebSite, Breadcrumbs, Article, FAQPage), single H1 rule, preloaded fonts, responsive images with srcset and high fetchpriority on LCP.
